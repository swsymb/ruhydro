# 🧪 Раствор для гидропоники

---
 
## Текущий профиль (PPM): 
```
NO3=155 NH4=5 P=55 K=255 Ca=145 Mg=55 S=92 Fe=3.0 Mn=0.48 B=0.52 Zn=0.26 Cu=0.050 Mo=0.050
```

## 🔬 **Микроэлементы**

- **💧 Маточный раствор:** 100 л
- **📏 Дозировка:** 10 мл на 1 л

| Компонент                         | Состав / Производитель | Масса на 100л |
| :-------------------------------- | :--------------------- | :------------ |
| **Хелат железа 6 %** [^1]<br><br> | EDDHA 6 %              | **2,1 г**       |
| **Кислота борная**                |                        | **0,1 г**     |
| **Аквамикс м**                    |                        | **1,3 г**     |


[^1]: FeDTPA, Fe 11% 1 г

## ✅ **Инструкция по применению**

1.  **Приготовление:**
    - Растворите каждый компонент в отдельной канистре в 1 литре чистой воды (желательно обратного осмоса).
    - Тщательно перемешайте до полного растворения.
    - Пометьте канистры метками.

2.  **Использование:**
    - Для приготовления 1 литра питательного раствора добавьте в воду по порядку:
        1.  `1 мл` раствора **"Микроэлементы"**
        2.  `10 мл` раствора **"А"**
        3.  `10 мл` раствора **"Б"**
    - Всегда соблюдайте последовательность и тщательно перемешивайте после каждого компонента!

> **⚠️ Важно!** Никогда не смешивайте концентраты "А" и "Б" напрямую вместе - это вызовет нерастворимый осадок. Смешивайте их только через воду.
